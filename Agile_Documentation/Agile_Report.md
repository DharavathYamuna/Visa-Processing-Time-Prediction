# Milestone 3 Documentation
## AI Enabled Visa Status Prediction and Processing Time Estimator
### Milestone Name
Milestone 3 – Predictive Modeling
### Objective
The objective of Milestone 3 is to develop and evaluate machine learning models that can predict visa processing time based on historical visa application data.
### Work Description
In this milestone, cleaned and preprocessed data from previous milestones was used to train regression models. The goal was to compare different models and select the best-performing model for predicting visa processing time.
### Tasks Performed
- Prepared final dataset for modeling
- Split data into training and testing sets
- Trained multiple regression models
- Evaluated models using MAE, RMSE, and R² score
- Compared model results
- Selected the best model
### Models Implemented
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
### Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
### Model Comparison Results
Linear Regression  
MAE: 7.26  
RMSE: 9.23  
R² Score: -0.39  
Random Forest  
MAE: 8.30  
RMSE: 11.52  
R² Score: -1.16  
Gradient Boosting  
MAE: 6.36  
RMSE: 9.75  
R² Score: -0.55  
### Best Model Selection
Among all models, Gradient Boosting Regressor achieved the lowest Mean Absolute Error (MAE). 
Therefore, it was selected as the final model for visa processing time prediction.
### Outcome
Milestone 3 was completed successfully with model training, evaluation, and best model selection as per the project plan.
### Conclusion
This milestone demonstrates the use of machine learning for predicting visa processing time and prepares the project for deployment in the next milestone.
