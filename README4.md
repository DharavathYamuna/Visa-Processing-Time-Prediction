# AI Enabled Visa Processing Time Estimator

## Project Overview
This project is an AI-enabled web application that estimates visa processing time based on user inputs such as visa type, applicant country, and processing center.

## Milestone 4 – Web App Development & Deployment
- Frontend developed using **Streamlit**
- Backend logic integrated within the Streamlit app
- Application deployed using **Google Colab**
- **ngrok** used to expose the local Streamlit server as a public URL

## Features
- User-friendly web interface
- Dynamic input selection
- Real-time processing time prediction
- Live deployment demonstration

## Deployment Details
The web application was deployed using Streamlit on Google Colab.  
ngrok was used to expose the local Streamlit server to a public URL.  
This allowed the application to be accessed through a browser without local installation.  
The deployment successfully demonstrated frontend–backend integration and live prediction functionality.
